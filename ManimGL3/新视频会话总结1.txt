# 六、f/c 部分目前的核心内容

定义：

`cₙ(t)=fₙ(t+1)`

f 和 c 的快速构造使用 Fibonacci doubling：

`F₂ₖ=(Fₖ+Fₖ₋₁)²`

`F₂ₖ₊₁=tFₖ²`

GF(2) 中：

`(a+b)²=a²+b²`

因此多项式平方不需要一般乘法，只需要把指数翻倍，相当于系数之间插入 0。

c 类似：

`c₂ₖ=(cₖ+cₖ₋₁)²`

`c₂ₖ₊₁=(t+1)cₖ²`

通过规模：

`n → n/2 → n/4 → ...`

而且每层数据规模也减半：

`n+n/2+n/4+...<2n`

所以 f/c 可以做到 O(n)。

这一节还会介绍 Lucas 定理作为另一种理解 Fibonacci 多项式系数的方法，但 Lucas 不是最终主算法的核心。

Lucas p=2：

`C(A,B)` 为奇数，当且仅当 B 的每个 1 位都包含在 A 的对应 1 位中。

应用到：

`C(n−k,k) mod 2`

可以直接判断某项系数是不是 1。

# 九、y 的闭式表示推导

定义：

`Sₙ=F₀+F₁+...+Fₙ₋₁`

可以推得：

`Sₙ=1+tSₙ₋₁+Sₙ₋₂`

以及：

`tSₙ=Fₙ+Fₙ₋₁+1`

第二个式子的证明是望远镜抵消：

`tSₙ`

`=tF₀+tF₁+...+tFₙ₋₁`

`=F₁+(F₀+F₂)+(F₁+F₃)+...+(Fₙ₋₂+Fₙ)`

中间项出现两次，在 GF(2) 中抵消，最后：

`=F₀+Fₙ₋₁+Fₙ`

`=1+Fₙ₋₁+Fₙ`

所以：

`Sₙ(t)=(Fₙ(t)+Fₙ₋₁(t)+1)/t`

注意：

这里的 `/t` 是**多项式除法/指数整体下移一位**。

不是 J 的逆。

因此严谨写法是：

`Yₙ=Sₙ(J)·𝟙=[(Fₙ+Fₙ₋₁+1)/t](J)·𝟙`

而不是直接写成：

`(Fₙ+Fₙ₋₁+1)/t·𝟙`

否则容易让人误解成除以矩阵。

# 十、为什么 Yₙ=Sₙ(J)·𝟙

不要引入临时的 `Zₙ`。

我之前已经明确表示，不喜欢为了证明额外定义一个 Z。

直接比较即可：

`Sₙ=1+tSₙ₋₁+Sₙ₋₂`

代入 J：

`Sₙ(J)=I+J·Sₙ₋₁(J)+Sₙ₋₂(J)`

作用于全1向量：

`Sₙ(J)·𝟙`

`=𝟙+J[Sₙ₋₁(J)·𝟙]+Sₙ₋₂(J)·𝟙`

而 Y 满足：

`Yₙ=𝟙+JYₙ₋₁+Yₙ₋₂`

初值也相同：

`S₀(J)𝟙=0=Y₀`

`S₁(J)𝟙=𝟙=Y₁`

所以通过递推/归纳：

`Yₙ=Sₙ(J)·𝟙`

# 十二、目前我对 S(J) 分治已经理解到哪里

这一部分之后的会话需要直接接着讲，不要重新从头讲一遍。

我已经理解：

`S(J)=S低(J)+J⁴S高(J)`

例如：

`S(J)`

`=(s₀+s₁J+s₂J²+s₃J³)`

`+J⁴(s₄+s₅J+s₆J²+s₇J³)`

也就是：

`S(J)=S低(J)+J⁴S高(J)`

为了直观描述左右移动，可以写：

`j(z)=z⁻¹+1+z`

其中：

* `z⁻¹`：向左移动1位
* `1`：保持原位
* `z`：向右移动1位

在 GF(2) 的形式移位运算中，利用 Frobenius：

`(a+b+c)²=a²+b²+c²`

所以：

`j²=z⁻²+1+z²`

`j⁴=z⁻⁴+1+z⁴`

`j⁸=z⁻⁸+1+z⁸`

一般：

如果：

`h=2ᵏ`

则：

`jʰ=z⁻ʰ+1+zʰ`

所以如果某个已经算好的结果 R 要乘 `Jʰ`，其中 h 是2的幂，不需要一般多项式乘法，只需要：

* R 左移 h
* R 保持原位
* R 右移 h
* 三份 XOR

# 十三、非 2 的幂不用单独计算

我问过：

* J⁶ 怎么办？
* 奇数怎么办？

结论是：

如果单独要求：

`J⁶`

可以用：

`6=4+2`

所以：

`J⁶=J⁴J²`

奇数：

`J³=J²J`

`J⁵=J⁴J`

`J¹³=J⁸J⁴J`

也就是指数二进制分解。

但是计算整个 S(J) 时：

## 更重要的是根本不用逐个求 J³、J⁵、J⁶……

例如 8 项的 S：

`S=S低+t⁴S高`

继续：

`S低=(s₀+s₁t)+t²(s₂+s₃t)`

`S高=(s₄+s₅t)+t²(s₆+s₇t)`

再继续拆。

整个递归中直接需要作为“跨层乘数”的只有：

`J¹、J²、J⁴、J⁸……`

其它指数会在这些组合中自然形成：

`J⁶=J⁴J²`

`J⁷=J⁴J²J`

所以文案应该强调：

> 我们不是先计算出所有 J⁰、J¹、J²……Jⁿ，再按照 S 选择，而是不断将 S 的系数二分，每次只需要处理 J 的 2 的幂次。

# 十四、S(J) 分治复杂度

递归形式：

`T(n)=2T(n/2)+O(n)`

因为：

* 拆成低半和高半两个约 n/2 的问题；
* 合并时，需要把高半已经得到的 O(n) 个系数做三次移动和 XOR；
* 每层总处理量 O(n)；
* 一共 log n 层。

所以：

`T(n)=O(n log n)`

可以使用主定理说明。

---

# 十五、S(J) 分治和 Fibonacci 倍增的关系

两者不是同一个公式，只是**算法思想相似**：

Fibonacci 倍增：

* 不再从 `F₀→F₁→...→Fₙ` 逐项计算；
* 利用 n/2；
* 利用 2 的幂和 GF(2) 平方特别简单。

S(J) 分治：

* 不再从 `J⁰→J¹→...→Jⁿ` 逐项计算；
* 将 S 的系数区间不断二分；
* 每次只直接使用 `J¹,J²,J⁴,J⁸...`；
* 同样利用 GF(2) 下 2 的幂特别简单。

可以概括成：

> 都是在避免逐项递推，而是利用二进制/二分结构跳跃计算。

但复杂度不同：

* Fibonacci 构造 f/c：O(n)
* S(J) 整体构造：O(n log n)

因为 S(J) 每层有两个子问题，而 Fibonacci 倍增只需要少数相邻的半规模结果，数据总量形成几何级数。

# 十六、非常重要的边界问题

这是之后必须保持严谨的一点。

`j(z)=z⁻¹+1+z`

以及：

`j²ᵏ=z⁻²ᵏ+1+z²ᵏ`

是**形式移位/无限序列意义下**的运算。

真正有限长度的棋盘中：

* 最左边没有左邻居；
* 最右边没有右邻居；
* 左移和右移在边界处并不是普通可交换的无限平移。

所以：

## 不要直接声称有限 n×n 的矩阵 J 本身满足：

`J²ᵏ = 左移2ᵏ + I + 右移2ᵏ`

实际算法还需要做**边界反射/扩展修正**。

视频目前可以先解释“内部/形式移位”的快速计算，再补一句：

> 实际有限棋盘的左右边界还需要单独处理，后面会通过对称延拓/边界反射解决。

# 十八、S(J)·𝟙 最后一步目前应该如何不用“卷积”解释

得到 S(J) 后，可以把它理解成：

> 对输入向量分别移动若干距离，然后根据一个 0/1 系数决定是否叠加。

例如有一串移动系数：

`... a₋₂,a₋₁,a₀,a₁,a₂ ...`

对于一般向量 v，每个结果位置都要叠加许多：

`aₖ·vᵢ₋ₖ`

一般仍可能 O(n²)。

但这里：

`v=𝟙=111...111`

所以所有有效的：

`vᵢ₋ₖ=1`

于是每个位置只需要把相应的一段 `aₖ` 异或起来。

相邻位置例如：

`Yᵢ=a₂⊕a₃⊕a₄⊕a₅⊕a₆`

`Yᵢ₊₁=a₃⊕a₄⊕a₅⊕a₆⊕a₇`

两者只有：

* 最左边一项退出；
* 最右边一项进入。

因此：

`Yᵢ₊₁=Yᵢ⊕a₂⊕a₇`

每个位置 O(1)。

或者定义前缀异或：

`Pₖ=a₀⊕a₁⊕...⊕aₖ`

任意一段：

`a_L⊕...⊕a_R`

都可以：

`P_R⊕P_{L-1}`

O(1) 得到。

所以 S(J) 的构造 O(n log n)，最终作用到全1向量这一部分可以做到 O(n)。

实际有限边界需要配合边界反射/修正。

# 二十、Frobenius 的名称

GF(2) 中：

`(a+b)²=a²+b²`

或者：

`(a+b+c)²=a²+b²+c²`

可以称为：

**Frobenius 自同态性质**

口语解释：

> 在 GF(2) 中平方时，所有交叉项都带系数2，而2=0，所以交叉项全部消失，只剩每一项分别平方。

后面 Fibonacci 倍增和 S(J) 分治都会重复利用它。

# 二十一、全局结构化简部分的重要数学关系

旧算法核心有：

`p=f+c`

并且由于：

`f(H)=0`

有：

`p(H)=c(H)`

所以实际上可以省掉 p。

注意不要写错成：

`c+f*q=1 mod f`

如果是在可逆情况下：

`p q=1 mod f`

则：

`(c+f)q=1 mod f`

`cq+fq=1 mod f`

所以：

`cq=1 mod f`

更一般、适用于奇异情况的关系应该写扩展欧几里得：

`s f+q c=g`

其中：

`g=gcd(f,c)`

代入 H：

`q(H)c(H)=g(H)`

不要让观众误以为 q 在所有情况下都是 c 的逆。

# 二十二、q/g 后面的核心内容

之后准备讲：

## Karatsuba

GF(2) 多项式乘法：

普通：

O(n²)

Karatsuba 将：

4 个半长度乘法

降为：

3 个半长度乘法

递归：

`T(n)=3T(n/2)+O(n)`

主定理：

`T(n)=O(n^log₂3)≈O(n^1.585)`

这一节需要从直观的多项式乘法开始讲。

# 二十三、q/g：快速除法、Newton、Half-GCD

旧扩展欧几里得多项式长除法是 O(n²)。

准备讲：

1. 多项式长除法
2. Bézout 系数
3. 倒序多项式
4. 形式幂级数求逆
5. Newton 迭代
6. 快速多项式除法
7. Half-GCD

GF(2) Newton 求逆有非常漂亮的形式。

如果：

`A G ≡ 1 mod tᵏ`

则可以构造更高精度：

`G_new=A G² mod t²ᵏ`

因为：

`AG=1+E`

所以：

`A·A G²=(AG)²=1+E²`

GF(2) 平方后误差次数翻倍。

Half-GCD 用 2×2 变换矩阵一次压缩两多项式，递归处理一半高位。

当前项目分析中，可以写类似：

`D(n)≤2D(n/2)+O(n^α)`

其中：

`α=log₂3`

所以最终可达到约：

`O(n^α)`

# 二十四、g 与秩缺陷的符号必须统一

非常重要：

设：

`d=deg(g)`

则：

* `d` = 秩缺陷
* `rank = n-d`
* d 是静默空间的维数
* 解的数量是：

`2^d`

不要说：

“d 是静默操作数”

因为静默操作的数量是 `2^d`，不是 d。

建议统一：

`r = rank`

`d = n-r = deg(g)`

避免一会儿把 r 当 rank，一会儿当 rank defect。

# 二十五、一个必须修正的结论

项目中有：

`deg(gₙ)=n`

当且仅当：

`n=0 或 n=4`

但：

## n=4 不是唯一解

n=4 时：

`d=4`

所以静默空间维数为4。

解数：

`2⁴=16`

不能写：

“n=0,4 时 deg=r=n 唯一”

这个是错误的。

# 二十七、奇异分支 x

设：

`d=deg(g)`

`r=n-d`

旧算法：

`D=g(H)`

然后通过反向叠加/回代求 x。

D 是带状的，带宽大致不超过：

`2d+1`

所以可以只处理有效区间。

如果粗略说：

`O(nd)`

是上界。

如果更严谨地分析旧回代有效工作量，更接近：

`O((n-d)d)`

最坏 O(n²) 发生在：

`d` 和 `n-d`

都与 n 同阶。

不是 d=n 时最坏；d=n 时反而 r=0。

之后 H64 一类的优化把这部分转为三角 Toeplitz 型系统：

`D(t)X(t)=R(t) mod t^ℓ`

利用 Newton + Karatsuba 做快速求解。

最终最坏也可以压到约 O(n^1.585)。
